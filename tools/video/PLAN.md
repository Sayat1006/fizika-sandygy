# Видео жоспары

## Орындау тәртібі
1. **Дайын видеоларды кеңейту** (бірден): `videos.json`-да `match` — сабақ тақырыбының өрнегі. publish.py оны барлық сыныптың барлық нұсқасынан (7–11, ЖМБ/ҚГБ) өзі табады.
   Сөзі ұқсас, бірақ мағынасы басқа сабақтар (мысалы, «Жарық қысымы», «инерция моменті») өрнекпен шектеледі.
2. **Топтар бойынша жаңа видео**: бір топ — 5 видео — бір PR. Әр топ: сахналарды жазу (kit.js) → кадр-парақпен тексеру → рендер → publish → build → тақтада тексеру → PR.
3. Реті: 7-сынып (3, 4-топ) → 8-сынып (5–8) → 9-сынып (9–12) → 10–11-сынып (13–16). 10–11-сыныпта алдымен 7–9-сыныптың видеосы `match` арқылы қосылады, жаңа видео тек жаңа тақырыпқа жасалады.
4. Әр видео: 1280×720, 18 с, мәтінсіз (тек белгілер мен өлшеуіш мәндері), ≤ 1 МБ. Физикалық шамалар шынайы есептеледі (сахна ішінде формуламен).

Бір сабаққа бірнеше видео болуы мүмкін — тақтада ауыстырғыш бар.
Видео тек көзбен көргенде түсінікті болатын құбылыстарға жасалады. SI бірліктері, есеп шығару, қайталау, БЖБ/ТЖБ сабақтарына видео жасалмайды.
