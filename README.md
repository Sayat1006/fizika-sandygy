# Сабақтас

Физика пәні мұғалімдеріне арналған сайт: ҚМЖ мен презентациялар ҚТЖ бойынша апта сайын жеке кабинетте ашылады.

## Құрылымы

| Жол | Не істейді |
|---|---|
| `web/` | **Бүкіл сайт — бір Vite + React + TypeScript қосымшасы**. `npm --prefix web run dev` — жергілікті іске қосу, `npm --prefix web run build` — `dist/` ішіне жинау (Vercel `buildCommand`) |
| `web/src/app/` | Негізгі сайт (`web/index.html`): `/` басты бет, `/app` кабинет, `/board?v=7&n=27` интерактивті тақта, `/samples` тегін үлгілер, `/oferta`, `/privacy`, `/admin` |
| `web/src/app/lib/config.ts` | **Kaspi, WhatsApp, Telegram, бағалар**, апта ережесі, курс нұсқалары |
| `web/src/app/styles/` | Дизайн жүйесі: `tokens.css` (түс, қаріп, өлшем, қозғалыс), компоненттер, беттер |
| `web/src/lab/` → `/lab` | **PHYSICS LAB 3D** — виртуалды физика зертханасы (`web/lab/index.html`, бөлек кіру нүктесі) |
| `public/` | Статикалық файлдар: `lessons.json`, `samples/`, `pv/` (алдын ала көрініс), `assets/` (иконкалар, қаріптер) |
| `api/download.js` | ҚМЖ, презентация, парақ, тақта сценарийі — жазылыммен (3 күндік сынақ та есептеледі); әр жүктеуді тіркейді; бір файлға 5 рет шек |
| `materials/decks/{v}-{n}.json` | **Анимациялы презентациялар** (7–9-сынып, 194 сабақ). Тақтада анимациямен ашылады (`web/src/app/deck/`, 3 стиль), жүктелетін .pptx сол файлдан жасалады. Қайта жасау: `cd tools/kmzh/gen && python3 export_pres.py 7 8 9`, сосын `python3 tools/deck/from_kmzh.py 7 8 9` (мазмұн + сызбалар) және `python3 tools/deck/build_all.py` (.pptx + «Қарау» превьюлері). `"custom": true` файлдар (7-5) қолмен жазылған, генератор оларды өзгертпейді |
| `materials/plans.json` | ҚМЖ-дан алынған сабақ кезеңдері (тақтаға); жаңа ҚМЖ қосқанда: `python3 tools/board/make_plans.py` |
| `materials/` | ҚМЖ (.docx), презентациялар (.pptx), жұмыс парақтары (.pdf). Сырттан тікелей ашылмайды, тек `api/download` арқылы |
| `supabase/functions/telegram` | Telegram бот: мұғалім Kaspi чегін ботқа жібереді → әкімшіге «✅ Растау / ❌ Бас тарту» батырмаларымен келеді → бір басқанда жазылым ашылып, мұғалімге хабар кетеді; дүйсенбідегі апталық хабар |

Дерекқор: Supabase жобасы `fizika-sandygy` (кестелер: `profiles`, `subscriptions`, `payment_requests`, `downloads`).

## Курс нұсқалары

- 7–9: бір нұсқа (`7`, `8`, `9`), аптасына 2 сағат.
- 10–11: `{сынып}-{zhmb|kgb}-{1|2|3}`, мысалы `10-zhmb-2`. Қазір дайыны: `10-zhmb-2`, `11-zhmb-3`.
- Жаңа нұсқа қосу: `public/lessons.json` ішіне `v` өрісімен сабақтар, `materials/manifest.json` ішіне `v:n` кілтімен файлдар. Нұсқа lessons.json-да пайда болса, кабинетте өзі «дайын» болады.
- Мұғалімнің сыныптары: `profiles.variants` (7–9 үшін `"7"`, `"8"`, `"9"`; 10–11 үшін нұсқа id). Кабинеттегі «Менің сыныптарым» арқылы бекітіледі (`profiles.classes_set`). Апталық сабақтар мен Telegram хабары тек осы сыныптар бойынша.

## Ережелер

- Тіркелгенде 5 сыныптың бәріне 3 күн тегін сынақ ашылады (`subscriptions.trial = true`).
- Telegram: Supabase-те `TELEGRAM_BOT_TOKEN` құпиясын қойып, `.../functions/v1/telegram?setup=1` ашу; `config.js` ішінде `telegramBot` толтыру. Апталық хабар: pg_cron, дүйсенбі 08:00.
- Google арқылы кіру: Supabase → Authentication → Providers → Google қосылған соң `config.js` ішінде `googleLogin: true`.

- ҚМЖ, презентация, жұмыс парағы және интерактивті тақта: сол сыныпқа жазылым болса (тегін сынақ та есептеледі), кез келген тақырып.
- Жазылымсыз «Қарау»: ҚМЖ-ның 1 беті, слайдтың алғашқы 3-і, парақтың 1 беті.
- Кабинетте «Осы апта» (ҚТЖ күні бойынша) және «Тақырып таңдау» (іздеумен, бүкіл жыл) көріністері бар.
- «Қарау»: ҚМЖ, слайд және парақты жүктемей-ақ беттер бойынша қарауға болады. Суреттер `public/pv/<хэш>/` ішінде (WebP), тізімі `materials/previews.json`-да; `api/download?…&view=1` жазылымсыз слайдтың алғашқы 3-ін, парақтың 1 бетін ғана береді. Жаңа материал қосқанда: `python3 make_previews.py kmzh|pres|ws` (PDF → WebP).
- Жүктелген ҚМЖ-ға мұғалімнің аты-жөні («Педагогтың аты-жөні») мен ҚТЖ бойынша сабақ күні («Күні») өзі жазылады (`api/_kmzh.js`).
- Баға: бір сыныпқа 1 ай – 1 490 ₸, 1 жыл – 9 990 ₸. Өзгертсеңіз, екі жерде өзгертіңіз: `public/assets/config.js` және дерекқордағы `plan_price` функциясы.
- Әкімші панелі: `/admin`. Логин `admin` (ішкі email: `admin@fizika-sandygy.kz`). `sayat.comp@gmail.com` email-імен тіркелген аккаунт та автоматты түрде әкімші болады.
