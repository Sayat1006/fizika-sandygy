# ElevenLabs: дыбыстау промпты

## 1. Дауыс (Voice Design → «Describe your voice»)

```
A warm, confident Kazakh-speaking woman in her early thirties, a friendly school teacher who explains things clearly. Native Kazakh pronunciation with correct қ, ғ, ң, ө, ұ, ү, ә, і sounds. Medium pitch, calm and trustworthy, slightly upbeat, smiling tone. Studio-quality, close microphone, no background noise, no reverb. Natural pace, clear diction, short pauses between sentences. Not a radio announcer, not overly dramatic — like a colleague recommending a useful tool.
```

Ер дауысы керек болса, бірінші сөйлемді ауыстырыңыз:
`A warm, confident Kazakh-speaking man in his mid thirties, a friendly physics teacher...`

## 2. Баптаулар

- Модель: **Eleven v3**. Дыбыстағаннан бұрын тілдер тізімінде Kazakh бар-жоғын тексеріңіз.
- Stability: **Natural**, шамамен 0,5.
- Жылдамдық: 1,0. Сахна ұзын шықса, 1,05–1,1 қойыңыз.
- Формат: MP3 44,1 кГц, 128 кбит/с.
- Әр сахнаны **бөлек** дыбыстаңыз, файл атауы кестедегідей болсын.
- Төртбұрыш жақшадағы белгілер ([warm], [pause] т.б.) — v3-тің дыбыс белгілері, олар оқылмайды. Басқа модель оларды дауыстап оқыса, жақшаларды өшіріңіз.

## 3. Мәтін — 16:9 видео (9 файл)

Мақсатты ұзақтық жақшада көрсетілген. Аздап ұзын не қысқа шықса, видео соған қарай реттеледі.

**01.mp3** (~8 с)
```
[tired, slightly ironic] Ертеңгі физика сабағына — қыэмжэ, презентация, жұмыс парағы... [pause] Тағы да түн ортасына дейін отырасыз ба?
```

**02.mp3** (~12 с)
```
[warm, confident] «Сабақтас» — жетінші мен он бірінші сынып аралығындағы физика мұғалімдеріне арналған сайт. Бүкіл оқу жылына алты жүз қырық алты сабақтың қыэмжэсы, алты жүз он бес анимациялы презентация, мыңдаған сұрақ пен тест — бәрі дайын.
```

**03.mp3** (~11 с)
```
[friendly] Тіркелу бір минут алады. Сыныптарыңызды белгілейсіз — [pause] кабинетте бүгінгі сабақтарыңыз күнтізбелік-тақырыптық жоспар бойынша өзі шығады.
```

**04.mp3** (~19 с)
```
[clear, explaining] Тақырыпты ашасыз: қыэмжэ, презентация және жұмыс парағы дайын тұр. Қыэмжэ Ворд форматында жүктеледі, аты-жөніңіз өзі жазылады, кез келген жерін өзгерте аласыз. [pause] Бөлімдік және тоқсандық жиынтық бағалау жинақтары да бар.
```

**05.mp3** (~25 с)
```
[energetic] Сабақта бір ғана батырма — «Тақтада ашу». [pause] Анимациялы слайдтар бүкіл экранда, артық ештеңе жоқ. Тақтаны басқан сайын келесі ой ашылады. Қаламмен үстінен жаза аласыз, ақ тақтаға ауыса аласыз, [pause] таймер мен кездейсоқ оқушы таңдау да осы жерде.
```

**06.mp3** (~17 с)
```
[curious, warm] Құбылысты сөзбен түсіндіру қиын болса — сабақтың үш өлшемді видеосын қосасыз. [pause] Ал виртуалды зертханада оқушылар тәжірибені өздері жасап, өлшеп көреді.
```

**07.mp3** (~21 с)
```
[excited] Оқушылар телефоннан кьюар-код арқылы қосылады, тіркелудің қажеті жоқ. Сұрақ жібересіз — [pause] әр оқушының жауабы бірден тақтада көрінеді. [smiling] «Түсіндіңдер ме?» деп болжаудың керегі жоқ.
```

**08.mp3** (~7 с)
```
[reassuring] Интернет үзіліп қалса да, алдын ала жүктелген сабақ тақтада ашылады.
```

**09.mp3** (~13 с)
